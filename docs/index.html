Features

Small dock, fewer clicks

Everything the dock does happens on the page you already have open — no companion app, no account, no sync service.

Floating dock

A compact control strip beside the player. Drag it to any vertical position and it stays there as you move between pages.

Forced HQ playback

The highest available quality is re-applied on every track change and on single-page navigation, not only when the tab first loads.

Picture-in-Picture

Pop the video out with play, pause, and return-to-tab controls that keep working while you use other applications.

Random play

Shuffle from your own listen history, recorded locally in browser storage. No account and no server to shuffle against.

Window controls

F11 fullscreen, maximize, restore, and minimize straight from the dock instead of reaching for window buttons.

Local-only by design

The extension declares a single host permission for music.youtube.com. Regular YouTube and every other site are untouched.

Install

Load it unpacked in three minutes

The extension is small enough to read end to end before you install it, which is exactly the point.

1

Clone the repository

You need the folder that contains manifest.json — Chrome loads the directory, not a packaged file.

git clone https://github.com/Nishanth1409/youtube-music-float-dock.git
cd youtube-music-float-dock
2

Load it in Chrome

Open the extensions page, turn on Developer mode, choose Load unpacked, and select the cloned folder.

chrome://extensions  →  Developer mode  →  Load unpacked
3

Turn the dock on

Open music.youtube.com, click the extension icon, then enable HQ playback and Show float dock.

4

After you change the code

Press Reload on the extension card, then refresh the YouTube Music tab so the content scripts re-inject.

chrome://extensions  →  Reload

FAQ

Good to know

Does this touch regular YouTube?

No. The manifest requests music.youtube.com only, so youtube.com is never injected into.

Where does listen history live?

In chrome.storage on your own machine. There is no backend, so there is nothing to upload it to.

Random play does nothing. Why?

History needs a few entries first. Play some music normally, then try Random again.

Is it on the Chrome Web Store?

Not at the moment. Load it unpacked from the repository — the source is short and readable.

Take back control of the player

Read every line, load it unpacked, and keep your listening data where it belongs — on your own machine.
